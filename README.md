# 🎴 Сундучки (Дипломат) — Онлайн карточная игра

Веб-версия классической логической карточной игры **«Сундучки»** (другие названия: *Дипломат*, *Literature*, *Fish* / *Go Fish*).

🌐 **Играть прямо сейчас (GitHub Pages):** [https://gr1nis.github.io/sunduchki/](https://gr1nis.github.io/sunduchki/)

---

## 🎯 Правила игры

1. **Колода**: выбор между **36 картами** (быстрая партия) и **52 картами** (классика).
2. **Раздача**: каждому игроку на старте выдается по **4 карты**, остаток — в колоду на столе («Базар»).
3. **Ход игрока**:
   - Активный игрок выбирает любого соперника за столом и спрашивает номинал (например: *«Есть ли у тебя Дамы?»*). Спрашивать можно только те номиналы, которые **уже есть у вас в руке**.
   - **Угадал**: соперник отдает **все** свои карты этого номинала, а вы **ходите снова**!
   - **Мимо («Рыба!»)**: вы берете 1 карту из колоды, и ход переходит следующему игроку по часовой стрелке.
4. **Сундучки**: как только игрок собирает 4 карты одного достоинства, они автоматически откладываются в **Сундучок** (+1 очко).
5. **Победа**: побеждает игрок, собравший наибольшее количество сундучков.

## 🚀 Особенности

- 🤖 **Умные AI-боты с памятью**: боты запоминают ходы соперников и используют логику для сбора сундучков.
- 👥 **Мультиплеер по ссылке**: создание комнат, легкий инвайт друзей по ссылке `?room=CODE` через WebSockets.
- 🎨 **Кастомизация карт и тем**: Королевская тема, Классическая и Киберпанк Неон.
- 🔊 **Web Audio эффекты**: реалистичные звуки раздачи карт, звона монет и сбора сундучков без внешних ассетов.
- 📱 **Адаптивный дизайн**: удобно играть как с компьютера, так и со смартфона.

## 🛠️ Локальный запуск (с мультиплеером)

```bash
# Установка зависимостей
npm install

# Запуск сервера
npm start
```

После этого откройте в браузере: `http://localhost:3000`
