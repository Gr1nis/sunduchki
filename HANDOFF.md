# Session Handoff: Веб-игра «Сундучки» (Sunduchki)

## 📌 Цель и платформы
- **Проект**: Карточная игра на логику «Сундучки» (Дипломат).
- **GitHub**: [https://github.com/Gr1nis/sunduchki](https://github.com/Gr1nis/sunduchki) (Public).
- **GitHub Pages**: [https://gr1nis.github.io/sunduchki/](https://gr1nis.github.io/sunduchki/) (200 OK, живой сайт).
- **Платформы**: Windows ↔ macOS (Zero-config, статический стек без сборщиков: HTML5, CSS3, ES Modules).

---

## 🏛 Ключевые архитектурные решения
1. **Zero-dependency клиентский стек**:
   - Чистый JavaScript (ES Modules: `app.js`, `localGame.js`, `botLogic.js`, `cardRenderer.js`, `sound.js`, `ui.js`).
   - Развертывание через GitHub Actions на GitHub Pages как из корня, так и из `./public` и `./docs`.
2. **ИИ-модель ботов (`LocalBotBrain`)**:
   - Локальная память каждого бота: запоминает публичные вопросы, ответы «да/нет», переходы карт между игроками и сброшенные сундучки.
   - Боты не жульничают: оперируют только видимой информацией стола и своей рукой.
3. **Трехэтапная механика допроса**:
   - Этап 1: Вопрос номинала (соперник отвечает «Да» или «Нет»).
   - Этап 2: Вопрос точного количества карт этого номинала.
   - Этап 3: Называние всех мастей этих карт (карты переходят только при точном совпадении всех мастей).
4. **Акустический саунддизайн без внешних файлов (`sound.js`)**:
   - Синтез живых звуков через Web Audio API (розовый шум с bandpass-фильтром для шелеста карт, перкуссионный резонанс для стука дерева, гармонические колокольчики).
5. **Мобильная эргономика**:
   - Поддержка `viewport-fit=cover`, `safe-area-inset-top/bottom` (Dynamic Island / чёлка / жестовая полоса).
   - Адаптивный динамический нахлест карт (`-26px`), центрированная арена соперников с 3D-мини-стопкой и бейджем количества.
   - Спич-бабблы над ботами и центральный баннер последнего действия.
   - Боковая выдвижная шторка истории ходов с независимым touch-скроллингом.

## ✅ Выполненные задачи
- [x] **Полная мобильная оптимизация интерфейса (iOS / Android / смартфоны / планшеты)**:
  - **Центрирование соперника и 3D-мини-стопка**: арена ботов строго центрирована сверху стола (`justify-content: center`). Вместо длинной полосы рубашек карт отображается компактная мини-стопка с бейджем количества карт (`🎴 5`).
  - **Карты строго в границах стола**: контейнер стола защищен `overflow: hidden`, базовый размер карт на смартфонах оптимизирован (`40px–54px`), увеличен адаптивный нахлест одинаковых рангов (`-26px`), исключая вылезание за зеленый борт.
  - **Поддержка Dynamic Island / Чёлки**: добавлены отступы `safe-area-inset-top` и `safe-area-inset-bottom`.
  - **Тач-ориентированная рука игрока**: горизонтальный центрированный веер с возможностью плавного свайпа (`-webkit-overflow-scrolling: touch`).
  - **Выдвижная боковая шторка истории ходов (Slide-over Drawer)**: на смартфонах история открывается по кнопке `📜` в шапке или кликом по баннеру хода.
- [x] **Наглядная живая история партии (Вариант 1: Speech Bubbles + Action Banner)**:
  - **Комиксные реплики ботов (Speech Bubbles)**: анимированные бабблы с репликами (`«Есть ли «10»?», «Думаю, 2 шт.!», «Масти: ♠ ♥! Забираю!»`).
  - **Информативный центральный баннер хода**: под колодой отображается статус текущего хода и результат последнего действия (`«📜 Бот спросил «10» у Вас ➔ НЕТ (Мимо)»`).
  - **Мгновенный вызов полной истории**: клик/тап по центральному баннеру хода открывает боковую шторку.
- [x] **Плавная прокрутка истории партии**:
  - Полное сохранение истории партии от первого хода без урезания.
  - `min-height: 0` для flexbox, `touch-action: pan-y`, блокировка сброса позиции скролла при появлении новых ходов ботов во время чтения.
- [x] **Кнопка «🏠 Меню»**: кнопка в шапке для быстрого выхода в главное меню с корректной остановкой игры.
- [x] **Крупный шрифт в главном меню**: увеличен кегль заголовков (`clamp(26px, 4.5vw, 36px)`), полей ввода (17px), селекторов, блока правил и кнопки запуска.
- [x] **Трёхэтапная механика правил**: Номинал ➔ Количество ➔ Масти.
- [x] **Акустический саунддизайн**: шелест карт, стук костяшек по дереву, гармонические колокольчики.
