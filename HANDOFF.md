# Session Handoff: Веб-игра «Сундучки» (Sunduchki)

## 📌 Цель и платформы
- **Проект**: Карточная игра на логику «Сундучки» (Дипломат).
- **GitHub**: [https://github.com/Gr1nis/sunduchki](https://github.com/Gr1nis/sunduchki) (Public).
- **GitHub Pages**: [https://gr1nis.github.io/sunduchki/](https://gr1nis.github.io/sunduchki/) (200 OK, живой сайт).

## ✅ Выполненные задачи
- [x] **Двухэтапная механика вопроса**:
  1. *Этап 1*: активный игрок спрашивает у соперника номинал («Есть ли у тебя 7?»). Соперник отвечает **«НЕТ!»** (промах, добор из колоды, переход хода) или **«ДА, есть!»**.
  2. *Этап 2*: только при ответе «ДА» активный игрок выбирает количество (`[1 шт.]`, `[2 шт.]`, `[3 шт.]`). При точном угадывании карты передаются, а игрок ходит снова! При ошибке в количестве карты остаются у соперника, но игрок теперь точно знает о их наличии.
- [x] **Анимация кражи карт**: добавлена задержка перерисовки руки (750ms), благодаря чему игрок отчетливо видит, как украденная карта загорается красным и улетает вверх из руки.
- [x] **Всплывающие уведомления (Toasts)**:
  - У игрока забрали карту: красный Toast с предупреждением и звуком.
  - Игрок забрал карту: зеленый Toast об успешном угадывании количества.
  - Игрок собрал сундучок: золотой Toast с короной и победным звуком.
  - Соперник ответил «ДА» или «НЕТ»: информационный Toast с репликой бота.
- [x] **Право продолжения хода при сборе сундучка**: если игрок собирает 4 карты в сундучок, ход не сгорает — он продолжает спрашивать.
