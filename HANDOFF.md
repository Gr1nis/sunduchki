## ✅ Выполненные задачи
- [x] **Полная мобильная оптимизация интерфейса (iOS / Android / смартфоны / планшеты)**:
  - **Центрирование соперника и 3D-мини-стопка**: арена ботов строго центрирована сверху стола (`justify-content: center`). Вместо длинной полосы рубашек карт отображается компактная мини-стопка с бейджем количества карт (`🎴 5`).
  - **Карты строго в границах стола**: контейнер стола защищен `overflow: hidden`, базовый размер карт на смартфонах оптимизирован (`40px–54px`), увеличен адаптивный нахлест одинаковых рангов (`-26px`), исключая вылезание за зеленый борт.
  - **Поддержка Dynamic Island / Чёлки**: добавлены отступы `safe-area-inset-top` и `safe-area-inset-bottom`, исключающие перекрытие элементов системными панелями.
  - **Тач-ориентированная рука игрока**: горизонтальный центрированный веер с возможностью плавного свайпа при накоплении карт (`-webkit-overflow-scrolling: touch`).
  - **Выдвижная боковая шторка истории ходов (Slide-over Drawer)**: на смартфонах история открывается по кнопке `📜` в шапке и не сжимает игровой стол.
- [x] **Наглядная живая история партии (Вариант 1: Speech Bubbles + Action Banner)**:
  - **Комиксные реплики ботов (Speech Bubbles)**: над карточкой бота во время его ходов и ответов всплывают живые анимированные бабблы с репликами (`«Есть ли «10»?», «Думаю, 2 шт.!», «Масти: ♠ ♥! Забираю!»`), мгновенно привлекая внимание игрока.
  - **Информативный центральный баннер хода**: под колодой отображается не только текущий статус, но и результат последнего действия (`«📜 Бот спросил «10» у Вас ➔ НЕТ (Мимо)»`). Запись остается на виду до следующего хода.
  - **Мгновенный вызов полной истории**: клик/тап по центральному баннеру хода открывает боковую шторку со всей хронологией игры.
- [x] **Трёхэтапная механика правил**: Номинал ➔ Количество ➔ Масти.
- [x] **Акустический саунддизайн**: живой шелест карт, стук костяшками по дереву, гармонические колокольчики.
