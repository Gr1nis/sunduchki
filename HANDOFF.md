# Session Handoff: Веб-игра «Сундучки» (Sunduchki)

## 📌 Цель и платформы
- **Проект**: Онлайн веб-версия карточной игры на логику «Сундучки» (Дипломат).
- **Платформы**: Windows ↔ macOS (кроссплатформенный запуск через Node.js и GitHub Pages).

## ✅ Выполненные задачи
- [x] Разработана игровая механика и стейт-машина правил (36 и 52 карты, раздача по 4 карты, передача карт, сбор сундучков, добор из колоды).
- [x] Реализован сервер синхронизации комнат и лобби на Node.js + Express + Socket.IO.
- [x] Разработан алгоритм AI-ботов (`BotBrain`) с отслеживанием памяти предыдущих ходов.
- [x] Создан адаптивный интерфейс игрового стола (`public/`) с поддержкой тем (Королевская, Классика, Киберпанк Неон) и карточным веером.
- [x] Добавлен Web Audio API синтезатор для звуковых эффектов без сторонних тяжелых ассетов.
- [x] Создан автономный движок `localGame.js` для мгновенной игры на GitHub Pages без обязательного сервера.
- [x] Настроен workflow автоматического деплоя GitHub Pages (`.github/workflows/deploy-pages.yml`) и папка `docs/`.

## 🏛️ Ключевые архитектурные решения
1. **Двухуровневая поддержка игры**:
   - **Серверный мультиплеер**: `server/src/index.js` + WebSockets для совместной игры с друзьями по ссылке `?room=CODE`.
   - **Клиентский оффлайн/Pages режим**: `public/localGame.js` позволяет запускать партию против ботов прямо на статическом GitHub Pages.
2. **Безопасность состояния стола**: сервер скрывает руки соперников от клиента, передавая только количество карт и рубашки.
